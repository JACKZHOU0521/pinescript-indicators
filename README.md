# Pine Script Indicators

A portfolio of TradingView Pine Script® indicators, each distilled from a
personal research library of **154 intraday price-action strategy families**
with honest evidence grading.

## Indicators

| Indicator | Description |
|---|---|
| [VWAP Signal Suite](vwap-signal-suite/) | Session VWAP + ±1σ/±2σ deviation bands, close-confirmed signals, 6 alerts |
| [Opening Range Breakout](opening-range-breakout/) | First-N-minute range high/low, close-confirmed breakout & retest-failure signals, 4 alerts |
| [Previous-Day Levels](previous-day-levels/) | Prior-day high/low/mid lines, breakout-close & wick-rejection signals, 6 alerts |
| [Overnight Range Breakout](overnight-range-breakout/) | Configurable overnight session range, day-session breakout signals, 2 alerts |

## Standards

- No repainting: signals appear only after bar-close confirmation
- Evidence-graded: every strategy mapping notes what the evidence actually
  supports — never marketed as "profitable"
- Education/research tools, not investment advice
